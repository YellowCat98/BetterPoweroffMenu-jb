# BetterPowerMenu

- A tweak that adds an enhanced power menu with more options. Doesn't even need to touch the screen!

- Why is the bundle ID com.yellowcat98.privacyinvader? I was initially going for a joke name (iInvadePrivacy) but as someone who really gets annoyed when tweaks name themselves in ways that make them hard to find, I opted for BetterPowerMenu instead. I decided to keep the bundle ID cause I doubt anyone's searching via bundle ID. (not that this tweak is ever gonna go outside my repo anyway)
